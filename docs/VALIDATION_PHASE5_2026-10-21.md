# EMA-Draft・Wallet画面用処理の結合検証

実施日：2026年10月21日（日本時間）

## 完成した変更

Wallet側で接続状態と表示結果の管理を分離しました。切断・入力変更・Wallet側の接続変更後に、古い応答が残高や検査結果を再表示することを防ぎます。通常の残高参照も、ETH残高・トークン残高・既存承認額を同じブロックハッシュで確認します。

このリポジトリのCIは、Walletの固定版 `5985f44f8930324ed55cd49ffd51f9557e19b341` を使用します。トークンのSolidityソース・本番配備記録・供給量は変更していません。

## ローカル結合検証

**24件成功、失敗・スキップ0件。** 実際のこのリポジトリの契約ソースをローカル模擬EVMへ配置し、チェーンID 8453・84532で各12件を確認しました。実際のBaseネットワークへの接続ではありません。

- 以前の22件を維持し、残高・桁数・最大承認額・接続分離・ブロック固定・ブロック置換時の拒否を検査します。
- 各チェーンIDで画面用の制御処理を通し、実際のトークン初期供給量、既存承認額0、同じブロックのETH残高が返ることを確認しました。
- 切断すると、画面用の結果と接続情報が消えることを確認しました。

Wallet側では別に196件のオフライン回帰検査が成功しています。HTTP配信2件とChrome上の模擬画面操作8件はWallet側CIで実行します。トークン側CIの24件は画面用制御処理の結合検査であり、ブラウザー検査とは区別しています。

## 再実行

Node 22以降を用い、このトークンのディレクトリから実行します。Walletは上記の固定版を使用し、パスを実際の配置に合わせます。

```sh
npm ci
npm run check
node --test ../ThreeCore-Wallet/integration/token-compatibility.test.mjs
```

CIは既存のコンパイル・コントラクト検査・型検査・読み取り検査に加え、この結合検証を実行します。
